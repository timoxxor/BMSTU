# Запуск проектов

Инструкция по сборке и запуску лабораторных работ.

## 1. Сборка через NOB (из корня репозитория)
В корне настроена система сборки **nob.h** от Tsoding.

### Первичный бутстрап (если бинарник `./nob` отсутствует):
```bash
cc -o nob nob.c
```
*(При любых дальнейших изменениях в `nob.c` или `nob.h` бинарник пересоберёт себя сам благодаря технологии Go Rebuild Urself™).*

### Команды NOB:
* Собрать конкретную лабораторную:
  ```bash
  ./nob lab3.1
  ./nob lab3.2
  ```
* Собрать и сразу запустить:
  ```bash
  ./nob run lab3.1
  # или
  ./nob lab3.1 run
  ```
* Очистить артефакты сборки (`build/` и `bin/`):
  ```bash
  ./nob clean lab3.1
  # или для всех сразу:
  ./nob clean
  ```
* Собрать все лабораторные работы:
  ```bash
  ./nob all
  ```

---

## 2. Сборка через Make (локально в папках)
Из папки нужной лабораторной (`~/.projects/BMSTU/labX/labX.Y`):
```bash
make run
```
или
```bash
make clean && make all
```

---

## Бинарники
Собранные исполняемые файлы сохраняются в `./bin/main` внутри папки соответствующей лабораторной работы.
