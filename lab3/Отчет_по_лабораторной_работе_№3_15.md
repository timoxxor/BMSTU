## ЧАСТЬ 1: Классы и перегрузка операций в Си++

### 1. Цель работы
Цель работы состоит в овладении практическими навыками разработки программ на языке Си++, использующих классы, динамическое управление памятью, конструкторы/деструкторы, семантику перемещения (Move Semantics), а также перегрузку стандартных операций (индексирования, потокового ввода/вывода, операторов присваивания и пользовательских бинарных операций).

### 2. Условие задачи (Вариант 15)
1. Разработать класс `Vector`, задающий динамический вектор целочисленных элементов (`int`) размерности $n$.
2. **Поля класса:**
   * Указатель на динамически выделяемый массив элементов (`int* data`);
   * Количество элементов / размерность вектора (`int size`).
3. **Методы и конструкторы:**
   * Конструктор без параметров (создает пустой вектор, размер 0, указатель `nullptr`);
   * Конструктор на основе одномерного массива размерности $n$;
   * Конструктор копирования (глубокое копирование выделенной динамической памяти);
   * Конструктор перемещения (`move constructor`), исключающий лишние аллокации;
   * Деструктор для корректного освобождения выделенной памяти.
4. **Перегрузка стандартных операций:**
   * Операция индексирования `[]` для чтения и модификации элементов вектора;
   * Операция присваивания с копированием `operator=`;
   * Операция присваивания с перемещением `operator=`;
   * Потоковые операции ввода `operator>>` (чтение из файла или консоли) и вывода `operator<<` (запись в файл или консоль).
5. **Индивидуальная операция (Вариант 15):**
   * Перегрузить побитовую операцию исключающего ИЛИ `^` (`XOR`) для двух векторов одинаковой размерности:
     $$\text{result}[i] = \text{vec}_1[i] \oplus \text{vec}_2[i]$$
   * При несовпадении размерностей векторов генерировать исключение `std::invalid_argument`.
6. Продемонстрировать разницу в работе конструкторов/присваиваний с копированием и с перемещением. Входные данные считывать из файла `input.txt`, результаты сохранять в файл `output.txt`. Исходный код разнести по заголовочному файлу (`Vector.hpp`) и файлу реализации (`Vector.cpp`).

#### Заголовочный файл `include/Vector.hpp`:
```cpp
#ifndef VECTOR_HPP
#define VECTOR_HPP

#include <iostream>
#include <cstddef>
#include <stdexcept>

/**
 * @brief Класс динамического вектора целых чисел (Вариант 15, Часть 1)
 */
class Vector {
private:
    int* data;  ///< Указатель на динамический массив элементов
    int size;   ///< Размерность (количество элементов) вектора

public:
    // 1. Конструктор по умолчанию (создает пустой вектор, размер 0)
    Vector();

    // Конструктор вектора заданного размера с одинаковыми значениями элементов
    explicit Vector(int n, int initVal = 0);

    // 2. Конструктор на основе одномерного массива размерности n
    Vector(const int* arr, int n);

    // 3. Конструктор копирования (глубокое копирование)
    Vector(const Vector& other);

    // 4. Конструктор перемещения
    Vector(Vector&& other) noexcept;

    // 5. Деструктор
    ~Vector();

    // 6. Операция присваивания с копированием
    Vector& operator=(const Vector& other);

    // 7. Операция присваивания с перемещением
    Vector& operator=(Vector&& other) noexcept;

    // 8. Перегрузка операции обращения по индексу []
    int& operator[](int index);
    const int& operator[](int index) const;

    // 9. Индивидуальная операция Варианта 15:
    // Побитовая операция XOR (^) с двумя векторами одинаковой размерности
    Vector operator^(const Vector& other) const;

    // Геттеры
    int getSize() const;
    const int* getData() const;

    // Операторы потокового ввода/вывода
    friend std::ostream& operator<<(std::ostream& os, const Vector& vec);
    friend std::istream& operator>>(std::istream& is, Vector& vec);
};

#endif // VECTOR_HPP
```

#### Файл реализации `src/Vector.cpp`:
```cpp
#include "Vector.hpp"
#include <iostream>
#include <utility>
#include <cstring>

// 1. Конструктор по умолчанию (пустой вектор)
Vector::Vector() : data(nullptr), size(0) {}

// Конструктор вектора заданного размера
Vector::Vector(int n, int initVal) : data(nullptr), size(0) {
    if (n < 0) {
        throw std::invalid_argument("Vector size cannot be negative");
    }
    if (n > 0) {
        size = n;
        data = new int[size];
        for (int i = 0; i < size; ++i) {
            data[i] = initVal;
        }
    }
}

// 2. Конструктор на основе одномерного массива размерности n
Vector::Vector(const int* arr, int n) : data(nullptr), size(0) {
    if (n < 0) {
        throw std::invalid_argument("Array size cannot be negative");
    }
    if (n > 0 && arr != nullptr) {
        size = n;
        data = new int[size];
        for (int i = 0; i < size; ++i) {
            data[i] = arr[i];
        }
    }
}

// 3. Конструктор копирования (глубокое копирование)
Vector::Vector(const Vector& other) : data(nullptr), size(other.size) {
    if (size > 0 && other.data != nullptr) {
        data = new int[size];
        for (int i = 0; i < size; ++i) {
            data[i] = other.data[i];
        }
    }
}

// 4. Конструктор перемещения
Vector::Vector(Vector&& other) noexcept : data(other.data), size(other.size) {
    other.data = nullptr;
    other.size = 0;
}

// 5. Деструктор
Vector::~Vector() {
    delete[] data;
    data = nullptr;
    size = 0;
}

// 6. Операция присваивания с копированием
Vector& Vector::operator=(const Vector& other) {
    if (this == &other) {
        return *this;
    }

    int* newData = nullptr;
    if (other.size > 0 && other.data != nullptr) {
        newData = new int[other.size];
        for (int i = 0; i < other.size; ++i) {
            newData[i] = other.data[i];
        }
    }

    delete[] data;
    data = newData;
    size = other.size;

    return *this;
}

// 7. Операция присваивания с перемещением
Vector& Vector::operator=(Vector&& other) noexcept {
    if (this == &other) {
        return *this;
    }

    delete[] data;

    data = other.data;
    size = other.size;

    other.data = nullptr;
    other.size = 0;

    return *this;
}

// 8. Перегрузка операции обращения по индексу []
int& Vector::operator[](int index) {
    if (index < 0 || index >= size) {
        throw std::out_of_range("Vector index out of range");
    }
    return data[index];
}

const int& Vector::operator[](int index) const {
    if (index < 0 || index >= size) {
        throw std::out_of_range("Vector index out of range");
    }
    return data[index];
}

// 9. Индивидуальная операция Варианта 15:
// Побитовая операция XOR (^) с двумя векторами одинаковой размерности
Vector Vector::operator^(const Vector& other) const {
    if (size != other.size) {
        throw std::invalid_argument("Vectors must have the same dimension for XOR operation (^)");
    }

    Vector result(size);
    for (int i = 0; i < size; ++i) {
        result.data[i] = data[i] ^ other.data[i];
    }
    return result;
}

int Vector::getSize() const {
    return size;
}

const int* Vector::getData() const {
    return data;
}

// Оператор вставки в поток (std::ostream)
std::ostream& operator<<(std::ostream& os, const Vector& vec) {
    os << "[";
    for (int i = 0; i < vec.size; ++i) {
        os << vec.data[i];
        if (i + 1 < vec.size) {
            os << ", ";
        }
    }
    os << "] (размер: " << vec.size << ")";
    return os;
}

// Оператор извлечения из потока (std::istream)
std::istream& operator>>(std::istream& is, Vector& vec) {
    int newSize = 0;
    if (is >> newSize) {
        if (newSize < 0) {
            is.setstate(std::ios::failbit);
            return is;
        }

        int* newElements = nullptr;
        if (newSize > 0) {
            newElements = new int[newSize];
            for (int i = 0; i < newSize; ++i) {
                if (!(is >> newElements[i])) {
                    delete[] newElements;
                    is.setstate(std::ios::failbit);
                    return is;
                }
            }
        }

        delete[] vec.data;
        vec.data = newElements;
        vec.size = newSize;
    }
    return is;
}
```

### 2. Условие задачи (Вариант 15)
1. **Базовый класс:** «вектор на плоскости» (`Vector2D`).
