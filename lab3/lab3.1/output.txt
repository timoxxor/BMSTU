========================================================
  Лабораторная работа №3. Часть 1. Отчет о работе
  Вариант №15: Побитовая операция XOR (^) для Vector<int>
========================================================

[1] Чтение векторов из файла input.txt через operator>>:
  Вектор 1 (v1): [15, 28, 42, 105] (размер: 4)
  Вектор 2 (v2): [7, 30, 19, 84] (размер: 4)

[2] Выполнение операции побитового XOR (v1 ^ v2):
  Результат (v_xor = v1 ^ v2): [8, 2, 57, 61] (размер: 4)
  Поэлементная проверка:
    Индекс 0: 15 ^ 7 = 8
    Индекс 1: 28 ^ 30 = 2
    Индекс 2: 42 ^ 19 = 57
    Индекс 3: 105 ^ 84 = 61

[3] Создание вектора на основе обычного C-массива:
  v_arr: [10, 20, 30, 40, 50] (размер: 5)

[4] Демонстрация оператора индексирования []:
  До изменения v_arr[2] = 30
  После v_arr[2] = 999: [10, 20, 999, 40, 50] (размер: 5)

[5] Конструктор копирования vs Конструктор перемещения:
  Исходный объект v_source: [10, 20, 30, 40, 50] (размер: 5) (data = 0x5608ebc758e0)
  После копирования v_copy(v_source):
    v_source: [10, 20, 30, 40, 50] (размер: 5) (data = 0x5608ebc758e0)
    v_copy  : [10, 20, 30, 40, 50] (размер: 5) (data = 0x5608ebc75900 - выделена новая память)
  После перемещения v_move(std::move(v_source)):
    v_source: [] (размер: 0) (ресурс отдан, data = 0)
    v_move  : [10, 20, 30, 40, 50] (размер: 5) (получил исходный указатель = 0x5608ebc758e0)

[6] Присваивание с копированием vs Присваивание с перемещением:
  После присваивания с копированием (v_target1 = v_for_assign):
    v_for_assign: [10, 20, 30, 40, 50] (размер: 5) (data = 0x5608ebc75920)
    v_target1   : [10, 20, 30, 40, 50] (размер: 5) (data = 0x5608ebc75940)
  После присваивания с перемещением (v_target2 = std::move(v_for_assign)):
    v_for_assign: [] (размер: 0) (ресурс перемещен, data = 0)
    v_target2   : [10, 20, 30, 40, 50] (размер: 5) (data = 0x5608ebc75920)

[7] Проверка обработки ошибок (разные размерности для XOR):
  Попытка выполнить: v1 (размер 4) ^ v_small (размер 2)...
  Успешно перехвачено исключение: Vectors must have the same dimension for XOR operation (^)
